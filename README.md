Student Information System

A desktop-based Student Information System developed using Java Swing and MySQL.
The application helps manage student records, attendance, marks, fees, notices, timetable, and extracurricular activities through a centralized management system.

Features
Secure Student Login System
Student Dashboard
Attendance Management
Marks and CGPA Management
Fee Management
Notice Board System
Timetable Management
Extracurricular Activity Records
Teacher/Admin Functionalities
Centralized MySQL Database
Password Hashing for Secure Authentication
Technologies Used
Java
Java Swing
JDBC
MySQL
Maven
IntelliJ IDEA
